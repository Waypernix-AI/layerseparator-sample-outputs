# LayerSeparator Sample Outputs

Downloadable sample archives for [LayerSeparator](https://layerseparator.com/) ([Image to PSD](https://layerseparator.com/image-to-psd)).

## Sample Archives

- [coffee-sample.zip](./coffee-sample.zip)
- [headphones-sample.zip](./headphones-sample.zip)
- [illustration-sample.zip](./illustration-sample.zip)

## Archive Contents

Each `.zip` archive contains:

- `source.webp` — source image
- `layer-N.webp` — separated bitmap layers
- `sample-layers.psd` — layered PSD file
- `sample-layers.zip` — PNG layers and manifest

## Notes and Limitations

- **Sample assets:** These archives are sample assets and are not all direct production exports. The PSD and PNG packages in `headphones-sample.zip` and `illustration-sample.zip` were assembled offline from existing public preview assets.
- **Bitmap layers:** Separated layers are raster bitmaps; any text is rasterized rather than editable text.
- **Reconstructed backgrounds:** Filled backgrounds are reconstructed pixels, not recovered original hidden pixels.
- **Editor testing:** The `sample-layers.psd` files have not been tested in an editor, and no editor compatibility is claimed.
